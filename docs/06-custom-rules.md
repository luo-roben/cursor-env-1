## 四种自定义类型

### 禁用词管理

```
┌─────────────────────────────────────────────────────────────────┐
│  禁用词管理                                                      │
│                                                                  │
│  操作方式: 直接输入词表，一行一个                                  │
│                                                                  │
│  ┌────────────────────────────────────────────────────────┐     │
│  │  禁用词列表                                    [+ 批量导入] │  │
│  │  ──────────────────────────────────────────────────── │     │
│  │  躺赚                                          [删除]  │     │
│  │  暴涨                                          [删除]  │     │
│  │  无脑定投                                      [删除]  │     │
│  │  稳赚不赔                                      [删除]  │     │
│  │  竞品公司A名称                                 [删除]  │     │
│  │  ...                                                   │     │
│  │  ────────────────────────────────────────────────────  │     │
│  │  [输入新禁用词...]                              [添加]  │     │
│  └────────────────────────────────────────────────────────┘     │
│                                                                  │
│  匹配方式:                                                       │
│  · 精确匹配 (默认) — 内容中包含该词即触发                         │
│  · 模糊匹配 (可选) — 允许中间插入空格/标点/零宽字符                │
│                                                                  │
│  匹配引擎: Aho-Corasick 多模式匹配                                │
│  性能: O(n), n=内容长度, 与禁用词数量无关                          │
│  延迟: < 1ms (万级禁用词表)                                       │
│                                                                  │
│  触发行为:                                                       │
│  · 命中禁用词 → 在快速过滤阶段直接标记违规                        │
│  · 不需要进入 LLM 审查流程                                       │
│  · 审查结果中标注: "命中企业禁用词"                                │
└─────────────────────────────────────────────────────────────────┘
```

### 必备声明管理

```
┌─────────────────────────────────────────────────────────────────┐
│  必备声明管理                                                    │
│                                                                  │
│  "以下声明必须出现在所有对外内容中"                               │
│                                                                  │
│  ┌────────────────────────────────────────────────────────┐     │
│  │  声明1 (必选):                                         │     │
│  │  ┌──────────────────────────────────────────────┐     │     │
│  │  │ XX基金管理有限公司                              │     │     │
│  │  └──────────────────────────────────────────────┘     │     │
│  │  匹配模式: [精确匹配 ▼]                                │     │
│  │  适用范围: [所有内容类型 ▼]                             │     │
│  │                                                        │     │
│  │  声明2 (必选):                                         │     │
│  │  ┌──────────────────────────────────────────────┐     │     │
│  │  │ 基金有风险，投资需谨慎                          │     │     │
│  │  └──────────────────────────────────────────────┘     │     │
│  │  匹配模式: [语义匹配 ▼]  ← 允许"投资有风险"等近似表述  │     │
│  │  适用范围: [营销物料 ▼]                                │     │
│  │                                                        │     │
│  │  声明3 (推荐):                                         │     │
│  │  ┌──────────────────────────────────────────────┐     │     │
│  │  │ 基金管理人不保证基金一定盈利，也不保证最低收益  │     │     │
│  │  └──────────────────────────────────────────────┘     │     │
│  │  匹配模式: [语义匹配 ▼]                                │     │
│  │  适用范围: [营销物料 ▼]                                │     │
│  └────────────────────────────────────────────────────────┘     │
│                                                                  │
│  匹配方式:                                                       │
│  · 精确匹配: 内容中必须包含完全一致的文字                         │
│  · 语义匹配: 用 Embedding 相似度判断(阈值 > 0.85)                 │
│    → 例: "基金有风险，投资需谨慎" 和 "投资有风险，请谨慎决策"     │
│      相似度 0.92，判为匹配                                       │
│                                                                  │
│  缺失行为:                                                       │
│  · 必选声明缺失 → 标记为 missing_element (严重)                   │
│  · 推荐声明缺失 → 标记为 missing_element (建议)                   │
└─────────────────────────────────────────────────────────────────┘
```

### 产品信息绑定

```
┌─────────────────────────────────────────────────────────────────┐
│  产品信息管理                                                    │
│                                                                  │
│  ┌────────────────────────────────────────────────────────┐     │
│  │  产品列表                                     [+ 新增产品] │  │
│  │                                                        │     │
│  │  ┌──────────────────────────────────────────────┐     │     │
│  │  │ 产品名称: XX沪深300ETF联接基金               │     │     │
│  │  │ 基金代码: 001234                             │     │     │
│  │  │ 基金类型: 股票型                              │     │     │
│  │  │ 风险等级: R3 - 中风险                         │     │     │
│  │  │ 成立日期: 2020-06-15                         │     │     │
│  │  │ 基金经理: 张三                                │     │     │
│  │  │ 业绩比较基准: 沪深300指数收益率×95%+银行活期... │     │     │
│  │  └──────────────────────────────────────────────┘     │     │
│  └────────────────────────────────────────────────────────┘     │
│                                                                  │
│  审查时自动关联:                                                  │
│  · 如果内容中提到产品代码 001234                                  │
│    → 自动加载该产品信息到审查上下文                                │
│    → 检查: 宣传语气是否匹配 R3 风险等级                           │
│      例: "低风险稳健投资" 用于 R3 产品 → 风险等级不匹配           │
│    → 检查: 是否使用了正确的基金全称                                │
│    → 检查: 业绩数据展示时是否标注了业绩比较基准                    │
└─────────────────────────────────────────────────────────────────┘
```

### 自然语言规则

```
┌─────────────────────────────────────────────────────────────────┐
│  自然语言规则 (高级功能)                                          │
│                                                                  │
│  "用自然语言描述你的合规要求，系统自动理解"                        │
│                                                                  │
│  ┌────────────────────────────────────────────────────────┐     │
│  │  规则1:                                                │     │
│  │  ┌──────────────────────────────────────────────┐     │     │
│  │  │ 所有营销内容中展示收益数据时，必须同时展示同   │     │     │
│  │  │ 期业绩比较基准的收益，不能只展示基金收益不展   │     │     │
│  │  │ 示基准对比。                                   │     │     │
│  │  └──────────────────────────────────────────────┘     │     │
│  │  优先级: [高 ▼]                                        │     │
│  │  适用内容类型: [全部 ▼]                                 │     │
│  │                                                        │     │
│  │  规则2:                                                │     │
│  │  ┌──────────────────────────────────────────────┐     │     │
│  │  │ 在社交媒体渠道的推文中，不得使用红色大字号标   │     │     │
│  │  │ 注收益率数字。收益率数字的字号不得超过风险提   │     │     │
│  │  │ 示文字字号的2倍。                              │     │     │
│  │  └──────────────────────────────────────────────┘     │     │
│  │  优先级: [中 ▼]                                        │     │
│  │  适用内容类型: [社交媒体推文 ▼]                          │     │
│  │                                                        │     │
│  │  规则3:                                                │     │
│  │  ┌──────────────────────────────────────────────┐     │     │
│  │  │ 所有对外宣传材料中引用的排名数据，必须来自于   │     │     │
│  │  │ 晨星、银河证券或海通证券的官方评级，不得使用   │     │     │
│  │  │ 非权威来源的排名。                              │     │     │
│  │  └──────────────────────────────────────────────┘     │     │
│  │  优先级: [高 ▼]                                        │     │
│  │  适用内容类型: [全部 ▼]                                 │     │
│  └────────────────────────────────────────────────────────┘     │
│                                                                  │
│  实现方式:                                                       │
│  · 自然语言规则直接拼入 LLM prompt 的"企业特殊要求"区块           │
│  · LLM 原生理解自然语言，不需要转换为任何"规则格式"               │
│  · 支持带条件的规则（如"仅适用于社交媒体渠道"）                    │
│    → 系统根据 content_type 过滤，只加载适用的规则                 │
│                                                                  │
│  限制:                                                           │
│  · 单条规则建议不超过 200 字                                      │
│  · 单个租户自然语言规则建议不超过 50 条                            │
│  · 超出后系统按优先级截断                                         │
└─────────────────────────────────────────────────────────────────┘
```

## 自定义规则在审查中的流转

```
企业自定义规则在审查中的加载位置:

  ┌─ 快速过滤阶段 ─┐     ┌─ ACE 上下文组装阶段 ─┐
  │                 │     │                       │
  │ • 禁用词匹配    │     │ • 产品信息关联         │
  │ • 必备声明检查  │     │ • 自然语言规则加载     │
  │                 │     │ (拼入 prompt)          │
  │ 耗时: < 5ms    │     │                       │
  └─────────────────┘     └───────────────────────┘

  禁用词和必备声明在 LLM 之前处理 (快, 确定性)
  产品信息和自然语言规则在 LLM prompt 中处理 (灵活, 语义理解)
```
